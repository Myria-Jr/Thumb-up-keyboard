# 👍 Daumen-Hoch-Tastatur (Android Native IME)

Eine echte Android-Systemtastatur, bei der jede Buchstabentaste ein **👍** ist – außer **Leertaste**, **Löschen (⌫)** und **Enter (↵)**.

## 🚀 APK automatisch auf GitHub bauen lassen (ohne Android Studio!)
1. Erstelle ein neues Repository auf GitHub.
2. Lade den Inhalt dieses ZIP-Archivs hoch.
3. Klicke auf deinem GitHub-Repo oben auf den Reiter **Actions**.
4. Dort läuft automatisch der Workflow **Build Android APK** durch.
5. Nach ~2 Minuten kannst du unter **Artifacts** die fertige `daumen-hoch-tastatur-apk.zip` (enthält die `app-debug.apk`) direkt auf dein Handy herunterladen und installieren!
